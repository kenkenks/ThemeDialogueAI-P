# ライセンスと帰属

目的・対象範囲：公開ソース・テスト・設計書・実験資料に適用するライセンスと、第三者由来部分の例外を明示する。

## 本プロジェクトの許諾

所有者の方針に基づき、本プロジェクトが許諾する権利を有するソースコード、テスト、設定、README、設計書、公開用に編集した実験資料をApache License 2.0で提供します。正式な全文は [LICENSE](../LICENSE) に収録しています。package.jsonとロックファイルのルートパッケージもApache-2.0です。

LICENSEは [Apache Software Foundationの公式テキスト](https://www.apache.org/licenses/LICENSE-2.0.txt) をそのまま収録しています。末尾の適用例のプレースホルダーは正式全文の一部です。既存24ファイルのApache-2.0ヘッダーを維持しています。

`private: true` はnpmへの誤公開を防ぐ設定で、GitHubのPublic設定や本ライセンスとは別のものです。

## 第三者由来部分

第三者の著作物、引用、外部リンク先、依存パッケージの権利を、本プロジェクトのApache-2.0で上書きしません。元のライセンス・著作権・帰属表示・利用条件を維持します。サービス名や商標への権利を与えるものでもありません。

追跡ファイルに同梱された上流NOTICEは確認されておらず、架空の権利者を記載したNOTICEは作成していません。今後第三者成果物を同梱する場合は、その条件を確認します。AI生成という理由だけで第三者権利の不存在を保証しません。

外部システムの設計思想への言及は概念上の参考情報です。参照元のソースコードは同梱しておらず、そのコードにライセンスを付与するものではありません。

## 外部依存

直接依存の表示は、Firebase・rules-unit-testing・TypeScriptがApache-2.0、React・React DOM・Vite・Vitest・Tailwind CSS・firebase-tools・各種型定義とプラグインがMITです。TypeScript等の上流LICENSE・NOTICEは依存パッケージ側に維持します。依存コード自体は本Gitリポジトリに同梱しません。

この記載は、すべての推移依存を同じライセンスと判断するものではありません。生成物やバイナリを別途配布する際は、配布物に含まれる依存のライセンス・帰属・NOTICEを確認して必要なものを同梱してください。
